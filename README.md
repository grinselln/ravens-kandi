# Raven's ♦️ Kandi

A photo portfolio with an admin dashboard, showcasing kandi and perler art created for festivals, concerts, and more. Kandi is handmade beaded (usually pony beads) jewelry and perlers are pixel like designs created by melting small plastic beads together. Both are traditionally traded at raves and festivals.

## Tech Stack
- Vite
- TypeScript
- React

## Running the Project
> **Note:** This is the frontend only. The [api repo](https://github.com/grinselln/ravens-kandi-api) must be running for the app to function.

1. Clone the repo
2. `yarn install`
3. Copy `.env.example` to `.env` and fill in `VITE_API_URL`
4. `yarn dev`
